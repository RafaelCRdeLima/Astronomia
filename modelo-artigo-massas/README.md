# Artigo do laboratório de dados — Capítulo 5

Esqueleto do artigo do **laboratório de dados do Capítulo 5**: pesar o Sol,
Júpiter, Saturno e a Terra pela terceira lei de Kepler.

## O que tem aqui

    main.tex                     o esqueleto, com as seções, a equação e os
                                 comentários dizendo o que cada parte cobra
    main.pdf                     como fica compilado
    udesc.png                    logotipo do cabeçalho
    figuras/log_p_log_a.pdf      EXEMPLO, feito com os dados reais do arquivo

A figura é um exemplo, para o modelo compilar de saída. **Troque pela sua.**

## Como usar

1. Baixe o `.zip`, descompacte e envie a pasta inteira ao Overleaf.
2. Preencha os campos marcados `PREENCHA` no topo do `main.tex`.
3. Substitua a figura de exemplo pela sua.
4. Escreva. Os comentários `%` dizem o que cada seção precisa conter.
5. Compile com pdfLaTeX **duas vezes**.

`02_terceira_lei_kepler.csv`, em
